# Changelog

## 1.0.0 — consolidated initial release

- Consolidated the project into one zero-runtime-dependency Node.js CLI.
- Added staged Git diff scanning with NUL-safe staged filename enumeration.
- Added provider-shaped credential, generic assignment, dotenv, and sensitive filename checks.
- Added suspicious outbound destination, endpoint allowlist, literal IP, and plain HTTP rules.
- Added a bounded credential-to-network identifier heuristic.
- Added TLS verification and shell-enabled subprocess checks.
- Added redacted text, JSON, and SARIF 2.1.0 reports.
- Added safe, idempotent pre-commit hook installation and managed-hook removal.
- Added deterministic synthetic demo, policy configuration, CI, and research protocol.
